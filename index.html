Questions

Quick answers.

Is it really free?

Yes. Zunx Client is free to download and use. You do not need a paid Zunx subscription to use the launcher or its core features. The website may display advertisements to help support the project.

Which Minecraft versions can I play?

Zunx is designed to let you choose Minecraft versions from 1.8 through the newest supported release. Older versions can be kept alongside newer versions, so you can switch between different setups without rebuilding everything each time.

Do I need to install Java?

No separate Java installation is required for the Windows installer. Java is included so a fresh Windows installation can get started without sending you to another website to find a compatible Java version.

Why is the download so big?

The installer can be larger because it includes Java and the files needed to make setup easier. The trade-off is that you do not have to download and configure Java separately before launching Minecraft.

Which computers does it work on?

The current installer offered on this page is for Windows. Zunx is intended to make the launcher setup simple on supported Windows systems, including machines where Java has not been installed before.

Do I need a Microsoft account?

You can start with offline play using a local name where the selected Minecraft setup permits it. For authenticated online services and servers that require a real account, sign in with Microsoft instead. Zunx supports both login paths so you can choose the setup that fits your use.

How do I add mods?

Open the Discover or Mods area, search for the mod you want, check its Minecraft version and loader compatibility, and press install. You can also add a mod file manually when you already have one. Zunx keeps the selected instance separate so its mod setup does not unexpectedly change another instance.

Where are my game files saved?

On Windows, the launcher uses your normal Minecraft data location under %APPDATA%\.minecraft. Zunx instances keep their own configuration and game content in the Zunx instance area, which helps separate mods, versions and worlds between different setups.

How do I update Zunx?

When a newer Zunx build is available, the launcher can notify you and guide you to the update. You can also install a newer installer over the existing installation. Your launcher data, instances and settings are intended to remain available after an update.

Can I give the game more memory?

Yes. Open the instance settings and adjust the memory allocation to match your computer and the size of the modpack you are running. Avoid assigning nearly all of your system RAM to Minecraft, because Windows and other applications still need memory.

Is Zunx made by Mojang or Microsoft?

No. Zunx Client is an independent third-party launcher. It is not made by, owned by, or officially connected with Mojang or Microsoft, and Minecraft remains a trademark of its respective owner.
