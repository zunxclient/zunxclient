Shaders and resource packs

Resource packs change how blocks and items look. Shaders add light, shadows and water effects.

How it helps you

  • Browse and install shaders and resource packs from inside Zunx.
  • Zunx installs the shader engine your loader needs, so shaders work right away.
  • Add your own pack files by dragging them in.
  • Search your downloaded packs to find them quickly.

How to use it

  1. Open your instance and go to the Resource packs or Shaders tab.
  2. Search and install a pack, or drag a file in.
  3. Start the game and turn the pack on in the game settings.

Tip: shaders need a good graphics card. If the game feels slow, try a lighter shader or turn it off.
