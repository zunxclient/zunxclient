Easy mod downloads

Adding mods is normally a lot of work: search websites, download files, copy them into folders. Zunx does it for you.

How it helps you

  • Search for mods inside Zunx and install them with one click.
  • Sort the list by most relevant, most downloaded, most followed, newest or recently updated.
  • Zunx shows popular mods for the Minecraft version you picked, so you can start fast.
  • A mod is only installed when every mod it needs has a version for your Minecraft version. This avoids broken games.
  • No more hunting for files on websites or putting files in the wrong folder.
  • Star your favorite mods. Favorites stay with you when you move to a newer Minecraft version.
  • If a mod is marked incompatible with one you already have, you see a red warning first.
  • Already have a mod file? Drag it into Zunx and it is added.

How to use it

  1. Open the Discover page.
  2. Search for a mod, or look through the popular ones.
  3. Press install and choose which instance should get it.

Tip: mods need a mod loader. Zunx can set up Fabric, Forge or NeoForge for you when you create an instance.
