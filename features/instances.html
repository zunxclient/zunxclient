Separate instances

An instance is one separate copy of Minecraft with its own mods, worlds and settings.

How it helps you

  • Keep a modded game and a plain game side by side.
  • Mods in one instance never break another instance.
  • Each instance has its own worlds, so nothing gets mixed up.
  • Want to use the default Minecraft folder instead? Tick the option when you create the instance.
  • Pick the instance you want right from the home page and press Play.
  • Set how much memory each instance can use.
  • Java is already inside Zunx, so there is nothing extra to install.

How to use it

  1. Open the Instances page.
  2. Press create and give it a name.
  3. Choose version and loader, then play.
