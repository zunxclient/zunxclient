Every Minecraft version

Zunx lets you play any Minecraft version from 1.8 up to the newest one, all from one launcher.

How it helps you

  • You do not need a different launcher for old and new versions.
  • Love old PvP servers? Play 1.8. Want the newest world? Play the latest release.
  • Zunx notices new Minecraft releases within a few minutes, so you can try them early.
  • Every version gets its own place, so one version never breaks another.

How to use it

  1. Open Zunx and go to Instances.
  2. Create a new instance and pick the Minecraft version you want.
  3. Press Play. Zunx downloads what that version needs.
