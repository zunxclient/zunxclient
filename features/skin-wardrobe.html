Skin wardrobe

The wardrobe is where you save your skins and choose which one to wear.

How it helps you

  • See your skin in a 3D preview before you use it.
  • Copy a skin from any player name with the look up box.
  • Drag a skin .png file onto the page to add it.
  • Give each skin a name so you can find it later.
  • Other Zunx players can see the skin you pick when you play.

How to use it

  1. Open the Wardrobe page.
  2. Add a skin: look up a name or drag in a .png file.
  3. Choose the skin you want to wear.

Note: skin sharing works between Zunx players. Players who do not use Zunx may not see it.
