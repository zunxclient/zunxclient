Fabric, Forge, NeoForge and OptiFine

A mod loader is the tool that lets Minecraft run mods. Zunx makes Fabric, Forge, NeoForge and OptiFine available from the instance setup for compatible Minecraft versions.

How it helps you

  • Choose Vanilla for plain Minecraft with no mods.
  • Choose Fabric for light, fast mods — available.
  • Choose Forge for the classic mod loader — available.
  • Choose NeoForge for the modern version of Forge — available.
  • Choose OptiFine for compatible versions when you want its graphics and performance features — available.
  • Zunx installs the loader for you. You never run an installer by hand.

How to use it

  1. Create a new instance.
  2. Pick your Minecraft version and your loader.
  3. Press Play. Zunx installs everything first.
