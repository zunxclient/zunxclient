General

Is it really free?

Yes. Zunx Client is free to download and use. You do not need a paid Zunx subscription to use the launcher or its core features. The website may display advertisements to help support the project.

Is Zunx made by Mojang or Microsoft?

No. Zunx Client is an independent third-party launcher. It is not made by, owned by, or officially connected with Mojang or Microsoft, and Minecraft remains a trademark of its respective owner.

Which computers does it work on?

The current installer offered on the download page is for Windows. Zunx is intended to make the launcher setup simple on supported Windows systems, including machines where Java has not been installed before.

Do I need a Microsoft account?

No. You can start with offline play using a local name where the selected Minecraft setup permits it. For online services and servers that require a real account, sign in with Microsoft instead. Zunx supports both login paths so you can choose the setup that fits your use.

Which Minecraft versions can I play?

Zunx is designed to let you choose Minecraft versions from 1.8 through the newest supported release. Older versions can be kept alongside newer versions, so you can switch between setups without rebuilding everything each time.

I have a problem. Who can I ask?

Download & install

Do I need to install Java?

No separate Java installation is required for the Windows installer. Java is included so a fresh Windows installation can get started without sending you to another website to find a compatible Java version.

Why is the download so big?

The installer can be larger because it includes Java and the files needed to make setup easier. The trade-off is that you do not have to download and configure Java separately before launching Minecraft.

Windows shows a warning when I run the installer. What should I do?

Windows can show a SmartScreen prompt for programs it has not seen many times. Only continue if you downloaded the installer from this website or from the official GitHub releases page. If you are not sure where a file came from, do not run it.

How do I update Zunx?

When a newer Zunx build is available, the launcher can notify you and guide you to the update. You can also install a newer installer over the existing installation. Your launcher data, instances and settings are intended to remain available after an update.

Where are my game files saved?

On Windows, the launcher uses your normal Minecraft data location under %APPDATA%\.minecraft. Zunx instances keep their own configuration and game content in the Zunx instance area, which helps separate mods, versions and worlds between different setups.

How do I uninstall Zunx?

Open Windows Settings, go to Installed apps, find Zunx Client and choose Uninstall. If you want to keep your Minecraft worlds, make a backup copy of them first.

Playing & mods

How do I add mods?

Open the Discover or Mods area, search for the mod you want, check its Minecraft version and loader compatibility, and press install. You can also add a mod file manually by dragging it in. Zunx keeps the selected instance separate so its mod setup does not unexpectedly change another instance.

What is a mod loader and which one should I pick?

A mod loader lets Minecraft run mods. Choose Vanilla for plain Minecraft, Fabric for light and fast mods, Forge for the classic loader, NeoForge for the modern version of Forge, or OptiFine for its graphics and performance features on compatible versions. Zunx installs the loader for you.

What if two mods do not work together?

If a mod is marked incompatible with one you already have, Zunx shows a red warning first. A mod is also only installed when every mod it needs has a version for your Minecraft version, which helps avoid broken games.

What is an instance?

An instance is one separate copy of Minecraft with its own mods, worlds and settings. Mods in one instance never break another, so you can keep a modded game and a plain game side by side.

Can I use shaders and resource packs?

Yes. Open your instance, go to the Shaders or Resource packs tab, and search or drag a file in. Shaders need a good graphics card, so try a lighter shader if the game feels slow.

How do skins work?

The Wardrobe saves your skins and shows a 3D preview. Look up a player name or drag in a .png file. Skin sharing works between Zunx players, and players who do not use Zunx may not see your skin. Offline accounts cannot change their skin on Mojang servers.

Performance

What does the FPS boost button do?

It installs a ready made list of well known performance mods, such as Sodium, Lithium and FerriteCore, so you do not have to search for each one yourself. The exact list depends on your loader.

How much FPS will I gain?

It depends on your PC, the Minecraft version, your settings and what else is installed. The charts on the Compare page are example figures, so the best test is to try FPS boost on your own computer.

Can I give the game more memory?

Yes. Open the instance settings and adjust the memory allocation to match your computer and the size of the modpack you are running. Avoid assigning nearly all of your system RAM to Minecraft, because Windows and other applications still need memory.

My game still lags. What can I try?

Lower the render distance, turn off or lighten shaders, press FPS boost on the instance, close other heavy programs, and keep the memory setting reasonable rather than maximum. OptiFine can also raise FPS without mods on compatible versions.

Does FPS boost work with every loader?

Zunx picks the performance mods that fit the loader you chose, so the list can differ between Fabric, Forge and NeoForge. Prefer no mods at all? OptiFine can raise FPS on compatible versions.

Privacy & safety

Does the Zunx website collect my personal information?

The website does not have accounts or forms and does not directly collect personal information. Our hosts and advertising partners may process standard technical data such as your IP address. See the full Privacy Policy.

Why are there ads on the website?

Ads help pay for the project so the launcher can stay free. They are provided by third-party ad networks, which may use cookies or similar technologies. Our Privacy Policy explains your choices.

Is my Microsoft account safe?

Microsoft sign-in is handled through Microsoft's own sign-in. Never share your password with anyone, and no one from Zunx will ask for it in Discord, email or any other chat.

Who can see my chosen skin?

Skin sharing works between Zunx players, so other Zunx players can see the skin you pick when you play. You are always in control of which skin and account you use.

Where can I read the full policy?

The Privacy Policy covers what the website collects, advertising, cookies and local storage, third-party services and your choices.
