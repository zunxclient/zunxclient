Your first instance

An instance is a separate copy of Minecraft with its own mods, worlds and settings.

  1. Open Zunx and go to Instances.
  2. Press Create and give the instance a name.
  3. Choose a Minecraft version and a loader (Vanilla, Fabric, Forge, NeoForge or OptiFine).
  4. Press Play. Zunx downloads and installs what that version needs first.

Make it faster

  1. Open your instance and press the FPS boost button.
  2. Wait a moment while the performance mods are installed.
  3. Press Play. Lower the render distance or use a lighter shader if the game still feels slow.

What you need

  • A Windows PC. The current installer is for Windows.
  • Nothing else to install. Java is included with the installer.
  • An internet connection for the first download of each Minecraft version.
